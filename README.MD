# Yuliana's Taqueria 

A restaurant menu web page built as the final project for Codédex's HTML course.

## About

Yuliana's Taqueria is a fictional Mexican restaurant menu page where users can browse menu items and place an order through an interactive form.

## Features

- Navigation bar with links to the menu and order form
- Menu section with three items (Tacos, Burritos, Enchiladas) including images, descriptions, and pricing
- Order form with:
  - Quantity inputs for each menu item
  - Side options via radio buttons
  - Add-on options via checkboxes
  - Special requests text area
  - Checkout submission button

## Built With

- HTML
- CSS
